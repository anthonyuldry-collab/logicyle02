# Fiche marque — PROVA
## Brand platform · Pitch FR/EN · Do / Don’t  
### Usage : deck investisseur · brief avocat · site · pitch commercial

> **Statut** : proposition branding (août 2026) — *candidate de repli / rebrand multi-sport* si LogiCycle est freiné juridiquement.  
> **Ce document n’est pas un avis juridique.** Toute adoption est conditionnée à : TMview / INPI / EUIPO (classes 9 · 42 · option 35) + domaines + App Store.

## 1. Décision en une phrase

**Prova** = la plateforme qui fait fonctionner une équipe de compétition comme un seul système — tous sports, à long terme.

---

## 2. Plateforme de marque

| Pilier | Contenu |
|--------|---------|
| **Marque** | **Prova** (casse : Prova · PROVA en logo wordmark) |
| **Catégorie à posséder** | L’OS des équipes de compétition |
| **Promesse** | Aligner athlètes, staff, courses, camps, logistique et réseau sur une seule plateforme |
| **Bénéfice client** | Moins de friction opérationnelle · plus de performance collective · un réseau qui recrute |
| **Preuve** | Ops course + camp/wellness + missions + scouting + (futur) portail organisateur |
| **Personnalité** | Européenne · exigeante · claire · terrain (pas “corporate froid”, pas “startup gadget”) |
| **Territoire** | Compétition high-performance (clubs → Conti → WT), puis triathlon / running / orga |
| **Ennemi** | Outils dispersés, Excel, WhatsApp, logiciels silotés qui ne parlent pas entre eux |

### Essences (3 mots)
**Alignement · Niveau · Terrain**

---

## 3. Architecture de nommage

```text
PROVA                         ← marque mère (toujours)
├── Prova Teams               ← clubs / équipes (cœur actuel = ex-LogiCycle)
├── Prova Organizer           ← portail organisateurs (roadmap)
├── Prova Missions            ← marketplace vacataires / staff
└── Modules sport             ← Cycling → Triathlon → Running
```

**Règle** : on ne crée pas une nouvelle marque par sport. On active un **module**.

**Transition** (si abandon LogiCycle) :  
*« LogiCycle devient Prova — même produit, ambition multi-disciplines. »*

### Pitch 20 secondes
**FR** — Prova remplace le patchwork Excel / WhatsApp / outils silotés des équipes de cyclisme (puis tri / run). Staff, athlètes, calendrier, camps, missions et recrutement tournent sur une seule plateforme — conçue pour le niveau compétition, prête pour le multi-sport.

**EN** — Prova replaces the Excel / WhatsApp / siloed-tool stack for competitive cycling teams (then triathlon and running). Staff, athletes, calendar, camps, missions and recruitment run on one platform — built for high-performance sport, designed to expand across disciplines.

### Pitch 60 secondes (investisseur)
**FR** — Le marché des logiciels équipes cyclistes est fragmenté et cher. Prova attaque d’abord le cyclisme compétitif (clubs → WorldTour) avec un OS opérationnel + réseau (missions, scouting, camps). Différenciation : prix, réseau, profondeur ops/camp vs acteurs installés. Roadmap : portail organisateur, puis triathlon, puis running — **sans changer de marque**. Cible : leader européen dual-track FR + EN.

**EN** — Team software in competitive cycling is fragmented and expensive. Prova starts with competitive cycling (clubs → WorldTour) as an operational OS plus network layer (missions, scouting, camps). Differentiation: pricing, network effects, ops/camp depth vs incumbents. Roadmap: organizer portal, then triathlon, then running — **same master brand**. Ambition: European leader, dual-track FR + EN.

## 5. Do / Don’t

### Do
- Parler **équipe de compétition**, pas “appli fitness”
- Ancrer le cyclisme **aujourd’hui**, ouvrir le multi-sport **demain**
- Utiliser le vocabulaire terrain : course, staff, convocations, camp, briefing, mission
- Garder un ton **direct, précis, européen**
- Toujours rattacher une feature à un **résultat d’équipe** (gain de temps, alignement, décision, recrutement)
- En EN : langage WT/clubs, pas jargon US “hustle”

### Don’t
- Ne pas dire “le LogiCycle du triathlon” une fois Prova lancé — **une seule marque**
- Ne pas surjouer l’AI / le purple SaaS / les badges “#1”
- Ne pas promettre le multi-sport comme déjà livré (roadmap ≠ produit)
- Ne pas coller au pure “logistique camion” (héritage Logi…) — Prova = **ops + perf + réseau**
- Ne pas utiliser Peloton, Strava, Garmin, Ippogee dans le naming ou le logo
- Ne pas inventer une étymologie faux-italien marketing (“Prova = pro + va”) — si on explique : *épreuve / course*

### Prononciation
- **FR** : *Pro-va* (comme “prova” italien, o ouvert)
- **EN** : *PRO-vah* (pas “prover”)
- Éviter l’acronyme forcé (P.R.O.V.A.)
