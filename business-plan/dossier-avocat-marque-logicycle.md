### Lot B — Constitution société (statuts)
Rédaction / relecture des **statuts** (SAS ou SASU) adaptés startup SaaS + Seed :
1. Objet social (édition logiciel SaaS sport / marketplace / services associés).  
2. Capital · catégories d’actions (si besoin).  
3. **Clause propriété intellectuelle** : tout code, design, doc, marque → propriété de la société.  
4. Pouvoirs président / directeur général.  
5. Cession d’actions · agrément · préemption (si associés futurs).  
6. Clause **vesting / bad leaver** (si pacte d’associés séparé ou dans statuts).  
7. Siège · durée · exercice social.  
8. Accompagnement greffe / annonce légale / Kbis (si inclus).

**Livrable attendu** : projet de **statuts** + checklist formalités création (ou mise à jour si société déjà créée).

### Lot C — Conditions générales & contrats SaaS (FR + EN)
Rédaction / relecture d’un pack **go-live décembre 2026** :

| Document | Public | Langues |
|----------|--------|---------|
| **CGU** (Conditions Générales d’Utilisation) | Utilisateurs plateforme (équipes, indépendants, staff) | **FR + EN** |
| **CGV** (Conditions Générales de Vente) / Contrat abonnement SaaS | Clients payants (B2B équipes + B2C indép.) | **FR + EN** |
| **Politique de confidentialité** | Tous | **FR + EN** |
| **DPA** (accord de sous-traitance RGPD art. 28) | Clients équipes / Enterprise | **FR + EN** |
| **Mentions légales** | Site public | FR (+ EN) |
| Clause **marketplace** | Commission ~12 % GMV · Stripe Connect · vacataires | Inclus CGU/CGV |
| Option | Template contrat **Pro / Enterprise / essai prolongé sur devis** | FR + EN |
| Option | **NDA** mutuel (pilotes WT) | FR + EN |

**Points métier à couvrir dans CGU/CGV** :
- Essai **14 jours** · abonnements mensuel/annuel · renouvellement / résiliation  
- Plans Club → Pro · indépendants · marketplace  
- Propriété des **données client** · export / purge · scouting **consent-based**  
- Limitation de responsabilité · SLA par plan (si applicable)  
- Sous-traitants : Firebase, Stripe, Google (OCR/IA le cas échéant)  
- Droit applicable / juridiction (France)  
- **Disclaimer** : non affilié à Logiscycle / Adam Hansen / Lotto (si avocat le recommande)  
- Coexistence outils tiers (ex. Ippogee) — pas d’exclusivité imposée au client

**Livrable attendu** : textes prêts à publier (`/legal/…`) + version Word/PDF signable Enterprise.
